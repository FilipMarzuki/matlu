# European Wildlife Species Backlog

100 species across Europe, organized by ecological role. Each entry maps to our game systems (archetype, hunt strategy, foraging, activity). Species are prioritized by how much they add to ecosystem variety — no duplicate niches.

**Legend:**
- **Archetype**: grazer / predator / critter / flocking
- **Hunt**: pursuit / ambush / pack / dive / — (not a predator)
- **Forage**: browsing / grubbing / scavenging / fishing / pecking / —
- **Activity**: D = diurnal, N = nocturnal, C = crepuscular
- **Priority**: 1 = high (tests a new system), 2 = medium, 3 = low (fills out variety)
- ✅ = already implemented
